GESTOR DE TRABAJO RAPIDO - COMO PROBARLO EN TU PC (Windows 10)
Equipo 7. App de pruebas: las claves de abajo son de ejemplo y no importa la seguridad.

Son tres partes que trabajan juntas:
  - La base de datos (PostgreSQL), carpeta bd/
  - La API (el "back"), carpeta api/
  - La app Android, carpeta android/
Los archivos que ejecutas estan todos en esta carpeta (ejecutar/). Se abren con doble clic.


=====================================================================
A. INSTALAR UNA SOLA VEZ (si ya lo tienes, salta al paso B)
=====================================================================

1. Git y el codigo
   Instala Git (https://git-scm.com) y descarga el proyecto:
       git clone <direccion del repositorio>
   Luego entra a la carpeta GestorTrabajo.

2. PostgreSQL 18 (sirve tambien la 16 o la 17)
   Descargalo de https://www.postgresql.org/download/windows/ (instalador de EDB).
   - Deja marcado todo lo que sale por defecto.
   - Puerto: 5432 (el que viene).
   - Te pide una contrasena para el usuario "postgres": ESCRIBELA EN UN PAPEL.
     La vas a necesitar en el paso B1.

3. SDK de .NET 10
   Descargalo de https://dotnet.microsoft.com/download (boton ".NET 10.0 SDK", NO el "Runtime").
   Para comprobarlo, abre PowerShell y escribe:  dotnet --list-sdks   (debe salir 10.x)

4. Android Studio
   Descargalo de https://developer.android.com/studio e instalalo con las opciones por defecto.
   Ábrelo una vez para que descargue el SDK de Android.

5. Un telefono Android con cable USB (lo mas facil)
   En el telefono:
     - Ajustes > Acerca del telefono > toca 7 veces "Numero de compilacion".
     - Ajustes > Opciones de desarrollador > activa "Depuracion por USB".
   El emulador de Android Studio tambien sirve, pero en algunas PC no arranca.


=====================================================================
B. LEVANTAR TODO (cada archivo se abre con doble clic en esta carpeta)
=====================================================================

PASO 1 - Base de datos         archivo: paso1-base-de-datos.bat
   Te pide la contrasena de "postgres" (la del paso A2). Al escribirla no se ve nada, es normal.
   Crea la base, las tablas, los departamentos y municipios, y las cuentas de ejemplo.
   Termina con "Base de datos lista".
   Se puede repetir cuantas veces quieras sin danar nada.

PASO 2 - API                   archivo: paso2-api.bat
   Configura la API y la enciende. La primera vez tarda un poco porque descarga paquetes.
   Cuando aparece "Now listening on: http://0.0.0.0:5000" ya esta lista.
   DEJA ESA VENTANA ABIERTA mientras pruebas. Para apagar la API: Ctrl+C.
   Comprobacion rapida: abre http://localhost:5000/swagger en el navegador.

PASO 3 - Telefono              archivo: paso3-telefono.bat
   Conecta el telefono por USB, acepta el aviso "Permitir depuracion USB" en su pantalla
   y abre este archivo. Debe decir "Listo".
   Repitelo cada vez que reconectes el cable o reinicies el telefono.

PASO 4 - La app Android
   1. Abre Android Studio > Open > elige la carpeta  GestorTrabajo\android
      (la carpeta "android", no la raiz del proyecto).
   2. Espera a que termine de sincronizar (barra de abajo). Si pregunta por instalar
      "Android SDK Platform 37" o algo faltante, acepta e instala.
   3. Arriba, elige tu telefono en la lista de dispositivos.
   4. Pulsa el boton verde Run (triangulo).
   5. En la pantalla de inicio de la app, toca "Acceso de prueba".

Para trabajar otro dia: PostgreSQL ya arranca solo con Windows, asi que normalmente solo
repites el PASO 2 (API), el PASO 3 (telefono) y el Run de Android Studio.

Un trabajador de otra zona (trabajador4, Fontaneria en San Salvador) sirve para comprobar que NO ve
las solicitudes de Mejicanos.

Recorrido para probar (es el de la demostracion):
   1. Administrador: en Catalogos ve los oficios y las zonas con su interruptor (activo o inactivo),
      y puede agregar o cambiar nombres. En Usuarios y reportes busca usuarios y ve las cifras.
   2. Cliente (Maria): Nueva solicitud, oficio Electricidad, llena los datos y Publicar.
   3. Trabajador (Luis): Trabajos de mi zona > abre la solicitud > precio y mensaje > Enviar propuesta.
      No se ve telefono ni direccion del cliente.
   4. Trabajador (Pedro): envia otra propuesta a la misma solicitud.
   5. Cliente (Maria): abre la solicitud > Ver propuestas, ve las dos y toca Aceptar en una.
   6. Trabajador (Pedro): en Mis propuestas ve la suya como Rechazada. Al cerrar y abrir la app
      sale el cuadro "Novedades" con el aviso.
   7. Maria y Luis: Ver seguimiento (Luis: Mis propuestas > la aceptada) muestra el telefono y la
      direccion del otro. Nadie mas puede verlos.
   8. Maria y Luis: se escriben desde la pestana Mensajes. Al cerrar y abrir la app, el otro ve en
      "Novedades" que tiene un mensaje nuevo.
   9. Luis: Marcar en proceso. Maria: Confirmar trabajo terminado. Los dos se Califican (de 1 a 5
      estrellas y un comentario). El promedio de cada uno cambia en su Perfil.
  10. Administrador: Usuarios y reportes > busca a Diana > Suspender. Diana ya no puede entrar.
      Despues Reactivar.
  11. Una solicitud publicada hace mas de 72 horas pasa sola a Vencida (la API lo revisa al
      arrancar y cada hora).
Para cambiar de cuenta: pestana Perfil > Cerrar sesion (el administrador, el icono de arriba a la derecha).
La lista completa de comprobaciones esta en la carpeta privada del equipo (docs/pruebas-android.md).


=====================================================================
D. SI ALGO FALLA
=====================================================================

"No se pudo conectar con el servidor" en la app
   -> La API no esta encendida (paso 2) o falta el tunel (paso 3). Repite el paso 3.
   -> No depende de que el telefono y la PC esten en la misma red Wi-Fi: va por el cable USB.

La app entra pero las listas salen vacias o con error
   -> Falta el paso 1, o la API se encendio antes de terminar el paso 1. Haz el paso 1 y
      reinicia la API (Ctrl+C en su ventana y vuelve a abrir paso2-api.bat).

Paso 1 dice que no encuentra PostgreSQL o falla la contrasena
   -> Revisa que PostgreSQL este instalado y que escribas la contrasena de "postgres" del paso A2.
   -> En PowerShell, "Get-Service postgresql*" debe mostrar "Running".

Paso 2 dice que no encuentra dotnet
   -> Instala el SDK de .NET 10 (A3) y cierra y abre de nuevo la ventana.

Paso 2 dice que el puerto 5000 esta en uso
   -> Ya hay una API abierta. Cierra esa ventana (Ctrl+C) y vuelve a intentar.

Android Studio: "jlink executable ... does not exist"
   -> Abre arreglar-java-android.bat, luego en Android Studio: File > Sync Project with Gradle Files
      y vuelve a pulsar Run.

El telefono no aparece en el paso 3
   -> Cambia el modo USB del telefono a "Transferencia de archivos" y acepta el aviso de
      depuracion. Prueba otro cable o puerto USB.

Quiero dejar la base limpia (borra todo)
   -> En PowerShell, desde la carpeta GestorTrabajo:
        .\bd\aplicar.ps1 -Reiniciar -DatosPrueba
      (te pide la contrasena de postgres). Despues reinicia la API.
   Si PowerShell dice que no permite ejecutar scripts, corre una vez:
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned


=====================================================================
E. COPIA DE SEGURIDAD DE LA BASE (pg_dump)
=====================================================================

Hace falta la contrasena de "postgres". En PowerShell, desde la carpeta GestorTrabajo
(cambia 18 por tu version de PostgreSQL si es otra):

   $pg = 'C:\Program Files\PostgreSQL\18\bin'

Respaldar (crea el archivo respaldo.dump):
   & "$pg\pg_dump.exe" -h localhost -U postgres -d gestor_trabajo_rapido -F c -f respaldo.dump

Restaurar. En una PC nueva corre antes  .\bd\aplicar.ps1  para crear la base y el rol gtr_api:
   & "$pg\pg_restore.exe" -h localhost -U postgres -d gestor_trabajo_rapido --clean --if-exists --no-owner respaldo.dump

Los archivos .dump no se suben a GitHub (estan en .gitignore): contienen datos de usuarios.
Para comprobar que la base esta sana (313 pruebas, no deja datos):   .\bd\aplicar.ps1 -Pruebas


=====================================================================
F. TELEFONO POR WI-FI EN VEZ DE CABLE (opcional)
=====================================================================

Con el cable USB todo funciona sin esto (paso 3). Si prefieres el Wi-Fi:

   1. PC y telefono en la misma red. Averigua la IP de la PC:
        Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notmatch '^(127|169\.254)' }
   2. Abre el puerto 5000 en el firewall de Windows (PowerShell COMO ADMINISTRADOR, una sola vez):
        New-NetFirewallRule -DisplayName "Gestor de Trabajo API" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow
   3. Comprueba desde el navegador del telefono:  http://IP-DE-LA-PC:5000/swagger  (debe salir Swagger).
   4. En android\app\src\main\java\com\utec\gestortrabajo\Config.java cambia URL_BASE a
      "http://IP-DE-LA-PC:5000/" y en android\app\src\main\res\xml\network_security_config.xml
      agrega esa IP como otro <domain> (HTTP sin cifrar: solo para desarrollo).
   5. Vuelve a pulsar Run en Android Studio.

Para el emulador de Android Studio la PC es  http://10.0.2.2:5000/  (no necesita firewall).
Antes de entregar la app: poner ACCESO_DE_PRUEBA = false en Config.java.
